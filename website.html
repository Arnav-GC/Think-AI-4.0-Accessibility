A few quick answers

Before you get started

What to expect from the current extension setup.

Do I need an API key to try every feature?

No API key is needed to explore the page's built-in demo controls. The project's AI descriptions and AI-assisted simplification require your own API key. Groq is the default provider, and Gemini and xAI Grok also work; the install guide explains where it is added.

Can I choose which accessibility controls are active?

Yes. Use the “Choose what to try” panel to select page-level options, then apply or reset your selection. The separate extension dock has its own controls when the extension is loaded.

Is the extension available in the Chrome Web Store?

The supplied project page says a Chrome Web Store listing is planned. For now, the guide uses Chrome's “Load unpacked” flow with the downloaded extension folder.

What happens to page content when I use AI features?

According to the project's setup notes, page images or text may be sent to your chosen AI provider (Groq by default) when you add a key and use the AI features. Review the extension's permissions and provider terms before using it with sensitive content.

Get OmniAccess AI for Chrome

Install in about a minute. Works in Chrome, Brave and Edge. No coding needed.

Download extension (.zip)
  1. Download and extract omniaccess-ai-extension.zip into any folder.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click “Load unpacked” and choose the extracted folder. Pin OmniAccess AI to your toolbar.
  4. Optional: open the side panel, go to AI & Tools, and choose Groq and paste a free API key from console.groq.com to turn on AI descriptions and simplification.

Privacy: gaze tracking, switch access and the offline simplifier run on your device. Page images or text are sent to your chosen AI provider (Groq by default) only if you add an API key. A Chrome Web Store listing is planned.
